# Karan Walekar — Personal Website

## Quick start
Open `index.html` locally to preview.

## Deploy
Recommended: GitHub Pages or Vercel.
1. Upload the folder to a GitHub repository.
2. Enable GitHub Pages, or import the repository into Vercel.
3. Point `karanwalekar.com` to the deployed site.
4. Update placeholder links (GitHub, Scholar, email) with your real profiles.

## SEO
The site includes a descriptive title, meta description, canonical URL, Open Graph metadata, and Person structured data.
